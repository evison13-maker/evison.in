# Evison's portfolio

A compact, responsive portfolio inspired by https://github.com/retrogtx/amritwt. Built with plain HTML, CSS, and JavaScript, with no installation or build step.

Run `npm run dev` and visit http://localhost:3000. Run `npm run check` to check JavaScript syntax.

## Update content

- Add projects to `dist/profile.js`. Each entry supports `title`, `description`, `technologies`, `url`, and `github`. The empty state automatically disappears when projects are added.
- Edit biography, education, email, or social links in `dist/index.html`.
- Add LinkedIn to the social links once your profile is ready.
- Change appearance in `dist/style.css`. The theme toggle saves the visitor's preference.

Education dates, degree specialization, project claims, and work experience are intentionally not invented.

The `dist` folder can be deployed to any static website host.
